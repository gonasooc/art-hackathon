## Design Context

현재 코드·사용자 결정 기준: 2026-11-07. 초기 두 목적지 영상 관람과 00칸만 구현하던 범위는 종료했다.

### Users
노트북 앞에 앉아 혼자 경험하는 예술 전시 관객. 자연스러운 시선으로 기차와 기억의 공간을 이동하고, 대상을 바라본 뒤 깜빡여 지운다. 첫 지원 환경은 내장 웹캠이 있는 데스크톱 Chrome이다. 보정이 어렵거나 카메라 없이 보여줄 때는 별도 자동 시연을 사용한다.

### Brand Personality
조용함, 몰입, 우연한 만남. 게임 조작법을 익히는 경험보다 몸과 시선이 공간에 관여하는 전시를 지향한다. 자동 시연은 접근성을 위한 대안이며 눈 추적 정확도 검증으로 해석하지 않는다.

### Aesthetic Direction
남색·금색 기차와 살구빛 자궁 공간을 시작으로 00–07의 서로 다른 기억을 잇는다. 보정·검증 뒤 행성 도입을 재생하고 기차 앞으로 연결한다. 00은 오브젝트 없이 통과하며 01–07은 응시·깜빡임 소멸, 마지막은 향의 깜빡임을 계기로 제공 영상으로 전환하는 피날레다. 07의 방향·비례·색·조명은 `docs/incense-reference.md`의 최신 영상 기준을 따른다. 별도의 도입·환경·효과음을 사용한다.

객차별 레퍼런스는 `docs/*-reference.md`를 따르며, 카페는 로컬 영상과 01–07 이미지 비교를 기록한 `docs/cafe-reference.md`가 최신이다. 사진과 실시간 절차형 3D 사이에 남은 차이를 명시한다.

### Design Principles

1. 일반 체험의 이동·회전은 검증된 시선만 사용한다. 머리·키보드·마우스 조향은 제공하지 않는다. 자동 시연과 개발용 수동 점검은 명시적으로 분리한다.
2. 상호작용 방법을 관객 화면의 문장으로 설명하지 않는다. 오브젝트의 은은한 윤곽빛과 응시 시 강조를 사용한다. 00에는 메인 오브젝트를 두지 않는다.
3. 카메라 핸드헬드는 이동 중 작은 진폭으로만 사용하고 롤 회전을 넣지 않는다. 동작 줄이기에서는 장식 이동을 멈춘다.
4. 원본 카메라 영상·눈 이미지·시선 이력을 업로드하거나 영속 저장하지 않는다. 보정·독립 검증 중에는 시선 파티클을 표시하지 않는다.
5. 시선 중심 빛은 최신 추정 좌표이며 주변 입자만 장식이다. 표시 끄기는 카메라 종료와 다르다.
6. 소멸은 일반 1.3초, 동작 줄이기 0.35초다. 인식 기준을 느슨하게 만들지 않는다.
7. 시작 화면은 제목·두 시작 버튼·카메라 개인정보 안내·홈 링크로 단순화한다. 제거한 장식 문구와 도입 건너뛰기를 다시 추가하지 않는다.
8. 조작 버튼은 남색 표면·금색 계열 테두리, 일관된 높이·간격·포커스 표시를 사용한다. 자동 시연에서는 마우스 호버·키보드 포커스 때만 상단 영역을 표시하고 터치에서는 항상 표시한다.
9. 주행 배경과 관객 이동 좌표를 분리하며, 자동 시연의 일시정지·탭 숨김에는 도입·소멸·소리·피날레도 멈춘다.
