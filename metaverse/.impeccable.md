## Design Context

### Users
노트북 앞에 앉아 혼자 경험하는 예술 전시 관객. 사용자는 자연스러운 시선이 공간의 여정에 관여하고, 관객이 도착한 곳에서 영상을 만나기를 원한다. 첫 대상은 내장 웹캠이 있는 노트북의 Chrome이다.

### Brand Personality
조용함, 몰입, 우연한 만남. 조작법을 익히는 게임보다 몸과 시선이 이끄는 전시 경험에 무게를 둔다. 이는 세션에서 사용자가 확정한 체험 의도를 요약한 표현이다.

### Aesthetic Direction
최신 방향은 Figma 레퍼런스의 남색·금색 기차와 살구빛의 유기적인 막이다. 보정 후 기차 앞에서 시작해 시선으로 열린 문을 통과하고, 움직이는 기차의 00칸에 들어간다. 사용자가 00칸 내부도 자궁을 추상적으로 표현하도록 확인했다. 창밖의 주행감과 관객의 이동은 분리한다. 한정된 통로와 낮은 진폭의 핸드헬드, 공간 안 영상 재생을 유지한다. 이번에 구현하는 칸은 00뿐이다.

### Design Principles
1. 이동과 회전은 검증된 눈의 시선으로 결정한다. 머리·키보드·마우스로 조향하지 않는다.
2. 화면의 장식과 안내는 작품 도착과 감상을 방해하지 않는다.
3. 핸드헬드는 낮은 진폭의 느린 움직임으로 제한하며 수평선을 기울이는 롤 회전을 사용하지 않는다.
4. 정지·도착·영상 관람에서 흔들림을 가라앉히며 동작 줄이기 설정에서는 끈다.
5. 시선 추론은 워커에서 수행하고, 화면 연출은 기존 렌더 루프에서 처리해 추가 추론이나 프레임 지연을 만들지 않는다.
6. 사용자의 후속 요청에 따라 시선 테스트에는 작은 빛과 입자 형상을 사용한다. 중심점은 실제 추정 좌표를 즉시 가리키고, 주변 입자의 장식 움직임이 정확한 위치를 대신하지 않게 한다. 표시를 끌 수 있으며 추적이 끊기면 숨긴다.

7. 최신 기획은 영상 대신 응시·깜빡임으로 메인 오브젝트를 연기처럼 지우는 경험이다. 01 병원은 붉은 벽·청록 조명·회색 바닥, 검은 표범과 금속 의자를 사용하며 사람은 넣지 않는다.
