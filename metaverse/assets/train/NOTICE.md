# 기차 레퍼런스 자산

사용자가 제공한 AKL Team 1 FigJam 보드의 원본 이미지이다. 기차·00칸 구현을 위한 레퍼런스 및 재질로 사용한다.

- `membrane.png`: 노드 [48:346](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=48-346)의 원본 PNG, 1672×941. 이미지 바이트를 변경하지 않고 곡면의 텍스처로 사용한다.
- `ground.png`: 노드 [48:372](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=48-372)의 원본 PNG, 1672×941. 바닥 텍스처로 사용한다.

다운로드한 만료성 자산 URL이나 접근 토큰은 포함하지 않는다. 기차 모델은 참조 이미지의 남색 차체, 금색 몰딩, 창문, 문, 계단, 지붕과 바퀴를 프로젝트의 Three.js 지오메트리로 구현한다.
