# 시선이 데려가는 곳

노트북 웹캠의 시선으로 기차에 올라 기억의 칸을 지나고, 메인 오브젝트를 바라본 뒤 깜빡이면 연기처럼 지워지는 1인칭 전시입니다. **현재 구현은 00–07의 8개 칸과 17개 소멸 대상**입니다. 2026-11-07 코드 기준입니다.

## 실행

저장소 루트 또는 이 폴더에서 실행합니다. 관람에는 별도 의존성 설치나 빌드가 필요하지 않습니다. Node.js 22 이상을 사용합니다.

```sh
npm start
```

| 용도 | 주소 |
| --- | --- |
| 일반 체험 | <http://127.0.0.1:5173/metaverse/> |
| 처음부터 자동 시연 | <http://127.0.0.1:5173/metaverse/?mode=visual> |
| 카페 수동 점검 | <http://127.0.0.1:5173/metaverse/?mode=inspect&car=04> |
| Pages 경로 확인 | <http://127.0.0.1:5173/art-hackathon/metaverse/> |
| 공개 주소 | <https://gonasooc.github.io/art-hackathon/metaverse/> |

첫 지원 환경은 내장 웹캠이 있는 노트북의 데스크톱 Chrome입니다. 일반 체험의 카메라는 로컬 주소 또는 HTTPS에서 사용합니다. 자동 시연과 수동 점검에는 카메라가 필요하지 않습니다.

## 모바일 간단 대응

휴대폰에서는 가로 화면의 **비주얼 테스트(자동 시연)**를 권장합니다. 작은 화면의 시작 페이지는 스크롤할 수 있고, 모바일 자동 시연에서는 하단 ‘조작’ 버튼으로 버튼 영역을 펼치고 접습니다. 펼친 버튼은 세로 3열·가로 6열로 배치합니다. 노치·하단 안전 여백, 최소 44px 버튼, 짧은 화면의 오류 패널 스크롤을 적용했습니다. 모바일 실제 눈 추적 정확도·기기별 GPU 성능·iOS 전체화면 지원은 보장하지 않으며, 이번 범위는 화면 배치와 자동 시연 터치 조작입니다.

세로 화면에서는 자동 시연의 관찰 구간과 수동 점검의 관찰 프리셋에서 01–06 메인 대상의 전체 경계에 맞춰 카메라 거리·화각을 조정합니다. 가로로 회전하면 기존 48° 화각으로 돌아옵니다. 일반 눈 추적 체험과 00·07의 영상 연결 구도는 변경하지 않습니다. 수동 점검에서 직접 카메라를 움직였다면 회전 시 그 위치를 강제로 덮어쓰지 않습니다.

## 현재 관람 흐름

**시선으로 시작 → 카메라 허용 → 보정 9점 → 독립 검증 6점 → 행성 도입부 → 기차 앞 → 시선으로 탑승 → 00–07 → 연기 글씨 피날레**

| 칸 | 공간 | 소멸 대상 |
| --- | --- | --- |
| 00 | 자궁 · 탄생 | 없음, 멈추지 않고 통과 |
| 01 | 병원 | 검은 표범, 금속 의자 |
| 02 | 유년의 집 | 벽화, 천장등, 선반 |
| 03 | 놀이터 | 미끄럼틀 놀이대, 그네 |
| 04 | 카페 | 찻잔 두 개, 안락의자 두 개, 테이블 |
| 05 | 숲 | 이끼, 잔설, 나무 |
| 06 | 병원 · 임종 | 검은 표범, 수의로 덮인 몸, 앤젤링 |
| 07 | 향이 놓인 자리 | 향·향로 |

찻잔 두 개와 의자 두 개는 각각 한 대상입니다. 병원에 사람은 배치하지 않습니다. 활성 순서는 `src/config.js`의 `JOURNEY_ORDER`이며 08–14는 이름만 등록된 비활성 확장 항목입니다.

- 이동·회전은 보정된 시선으로만 제어합니다. 머리·키보드·마우스로 대신 조향하지 않습니다. 중앙을 보면 현재 방향을 유지합니다.
- 보행 속도는 **2.7m/s**입니다. 기차의 배경 주행과 관객의 실제 이동 좌표는 별개입니다.
- 접근 중에도 상호작용할 수 있으며, 관찰 구간에서는 보행을 멈춥니다. 실제 메시를 6m 이내에서 응시하고 양안을 깜빡여 대상을 소멸시킵니다.
- 소멸 연출은 **1.3초**, 동작 줄이기에서는 **0.35초**입니다. 응시·깜빡임 인식 기준은 그대로 유지합니다. 같은 효과를 자동 시연·수동 점검에서도 사용합니다.
- 01–06은 모든 대상이 사라지면 출구로 이동합니다. 07은 향 소멸 시작과 함께 제공된 `향2.mp4`의 준비된 첫 프레임으로 2.2초 동안 부드럽게 전환한 뒤 영상을 재생하고, “No Click, / Just Blink.”가 나타나는 영상의 마지막 프레임을 유지합니다. [향 공간·영상 피날레](docs/incense-reference.md).
- 상호작용 설명 문장 대신 낮은 밝기의 윤곽빛으로 대상을 표시합니다. 자세한 판정은 [오브젝트·병원 기획](docs/hospital-object-plan.md)을 참고하세요.

01 병원·06 임종의 표범은 제공된 두 방향별 이미지에 맞춰 공통 모델로 보완했습니다. 몸통·목·다리는 연속 표면으로 연결하고 얼굴·발·털 무늬 디테일을 추가했습니다. [표범 형상과 남은 차이](docs/leopard-reference.md).

## 도입부와 소리

보정·검증 뒤 `assets/films/planet-womb.mp4`를 재생합니다. 10.4초부터 3.2초 동안 3D 공간과 겹쳐 기차 앞으로 연결하며, 그동안 이동·오브젝트 진행은 멈춥니다. **도입 건너뛰기 버튼은 없습니다.** 영상 로드에 실패하면 오류 화면의 ‘기차 앞에서 계속’으로 복구할 수 있습니다.

동작 줄이기에서는 첫 프레임을 1.8초 유지한 뒤 1.2초 페이드합니다. 처음부터 시연·재시작에는 도입부가 포함되고, 도입 중 시연 전환은 현재 시간을 유지합니다. 이미 관람 중인 경우 도입을 다시 재생하지 않습니다. [도입 연출](docs/planet-prologue.md).

영상 파일 자체는 무음이지만 **체험 전체가 무음인 것은 아닙니다.** `src/journey-audio.js`가 별도 오디오를 관리합니다.

시연 일시정지·탭 숨김에서 소리도 멈추고 종료·재시작에서 초기화합니다. URL로 자동 시연을 바로 열면 브라우저 정책에 따라 첫 클릭·키 입력 전 소리가 차단될 수 있습니다. 수동 점검은 공간 확인용이며 일반 체험의 오디오 진행을 재현하지 않습니다. 단, 수평으로 이동할 때 발자국 소리는 재생합니다. 시선 체험·자동 시연도 실제 보행 중에만 발소리를 재생하며, 관찰·도입·카메라 회전·수직 이동·피날레에는 재생하지 않습니다. 시연 일시정지·탭 숨김·종료에서는 즉시 멈춥니다. 초기 발소리 볼륨은 `src/journey-audio.js`의 `FOOTSTEP_VOLUME = .18`에서 조절합니다.

향 영상은 비율을 유지하며 한 번 재생합니다. 동작 줄이기에서는 최종 정지 프레임을 표시하고, 영상 실패 시 기존 3D 연기 글씨로 복구합니다. 영상에 포함된 소리는 사용하지 않으며 기존 향 음원을 별도로 유지합니다.

## 시작 화면과 조작 영역

시작 화면에는 작품 제목, **시선으로 시작**, **비주얼 테스트**, 카메라 개인정보 안내와 프로젝트 목록 링크를 둡니다. 장식용 소개 문구·상단 영문 부제·하단 문구는 제거했습니다.

기본 체험에서는 이동 중 **흔들림 끄기**, 관찰·이동 중 **시선 표시 끄기 / 켜기**, **체험 종료**를 제공합니다. 현재 추정된 시선은 작은 중심 빛으로 표시하며 주변 입자는 장식입니다. 보정·독립 검증에서는 표시하지 않습니다. 눈 감음·추적 실패·오래된 입력에서는 중심점을 숨깁니다.

### 자동 시연

첫 화면의 **비주얼 테스트**는 카메라 없이 도입부터 피날레까지 자동으로 시연합니다. `?mode=visual`도 같은 동작이며 `car` 값으로 시작 칸을 건너뛰지 않습니다.

보정 실패나 체험 도중에는 **자동 시연으로 전환**으로 이어갈 수 있습니다. 현재 위치·칸·이미 소멸한 대상과 소멸 진행을 유지하고, 카메라와 워커는 종료합니다. 입장 전의 새 시연은 도입부부터 시작하며 도입 영상 실패 상태는 기차 앞으로 복구합니다. 자동 시연은 실제 이동·응시 판정·깜빡임·소멸을 공유하지만 보정 통과나 사람의 눈 추적 정확도를 입증하지는 않습니다.

- **일시정지 / 계속 시연**, **이전 칸 / 다음 칸**, **처음부터 시연**, **전체화면 / 전체화면 해제**, **시연 종료**는 높이 44px 이상의 공통 조작 영역에 배치합니다.
- 마우스 환경에서는 기본적으로 숨기고, 버튼 주변 상하 24px·좌우 20px 영역에 마우스를 올리면 표시합니다. 벗어나면 다시 숨깁니다.
- 키보드로 버튼에 접근하면 표시하고, 터치 모바일에서는 ‘조작’ 버튼으로 펼치고 접습니다. 좁은 화면에서는 ‘자동 시연’ 상태 라벨을 숨깁니다.
- **전체화면**은 도입 영상·3D 공간·조작 영역이 포함된 페이지 전체를 확장합니다. 해제 버튼이나 브라우저의 Esc로 복귀하면 버튼 상태도 갱신됩니다. 미지원 환경에서는 버튼을 숨기며 요청 실패 시 재시도 안내를 표시합니다.
- **이전 칸 / 다음 칸**은 탑승 후 00–07 사이를 이동합니다. 도입·탑승 전에는 비활성화하고, 00의 이전·07의 다음도 비활성화합니다. 출발 칸의 진행 중 소멸 효과를 정리하고 도착 칸의 대상을 복원해 입구부터 다시 시연합니다. 그 외 칸의 상태와 현재 일시정지 여부는 유지하며, 이전 소리는 멈추고 도착 칸의 소리는 재생 상태에서 시작합니다. 일반 시선 체험에는 이 이동 버튼을 제공하지 않습니다.
- **처음부터 시연**에서만 전체 여정을 초기화합니다. 일시정지·탭 숨김에서는 도입·소멸·피날레 진행도 멈춥니다.
- 피날레가 완성되면 별도의 다시 시연·처음으로 버튼도 표시됩니다.

### 개발용 수동 점검

`?mode=inspect&car=04`는 자동 시연과 별개입니다. 기차 앞과 00–07 선택, 카메라 프리셋, 드래그 회전, WASD·화살표 이동, Q/E 높이 조정, 소멸·복원, 밝기, 애니메이션 정지, H 키로 도구 숨김을 제공합니다. 일반 시선 체험에 키보드 이동을 추가한 것은 아닙니다.

## 보정·개인정보

보정은 9개 학습점 안에서 교차 검사로 선형·2차 회귀를 비교하고, 학습에 사용하지 않은 별도 6점으로 검증합니다. 첫 점은 1.8초, 이후 점은 0.9초 준비 후 프레임 촬영 시각을 기준으로 표본을 수집합니다. 검증 한계는 중앙 오차 0.16, 최대 점 오차 0.24, 방향 일치 최소 5/6, 흔들림 최대 0.12입니다. 한두 점만 실패하면 해당 점을 한 번 재확인하며 전체 기준을 다시 적용합니다.

원본 프레임은 기기 내 워커에서 분석합니다. 눈 이미지·시선 이력은 업로드하거나 영속 저장하지 않습니다. 콘솔의 `[gaze-check]`는 오차·방향·흔들림과 추론 경로의 집계 진단입니다. 시선 표시 끄기는 화면 표시만 바꾸며 카메라는 마지막 향 소멸·체험 종료·취소·자동 시연 전환에서 종료합니다. 도입 중에는 추적 처리를 일시정지합니다.

조명·안경·카메라 위치·자세가 정확도에 영향을 줍니다. 합성 입력 테스트 통과를 실제 사용자의 보정 성공률로 해석하지 않습니다.

## 개발과 검증

아래 명령은 `metaverse/`에서 실행합니다.

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

`build`는 고정 의존성의 배포 파일을 `vendor/`로 복사하고 지정한 모델·영상·기차 텍스처의 크기와 해시를 `assets/manifest.json`에 기록합니다. **현재 매니페스트에는 `assets/audio/`가 포함되지 않습니다.** 별도 소리 파일은 배포에 포함해야 합니다. 향 피날레 MP4와 첫·마지막 정지 프레임은 매니페스트에 포함합니다. 정적 배포에는 HTML·CSS·`src/`·`vendor/`·`assets/`가 필요하며 백엔드는 없습니다.

변경 범위에 맞춘 브라우저 검사는 다음처럼 실행합니다.

```sh
npm run test:e2e -- tests/browser/prologue.spec.mjs
npm run test:e2e -- tests/browser/demo-controls.spec.mjs
npm run test:e2e -- tests/browser/cafe.spec.mjs
npm run test:e2e -- tests/browser/incense-finale.spec.mjs
```

실제 워커·카메라 초기화 검사와 추적기 경계의 합성 눈 특징 검사를 구분합니다. 테스트용 공개 얼굴 이미지가 없으면 `.cache/fixtures/`로 내려받습니다. 최신 변경별 실행 결과와 미확인 범위는 [검증 기록](docs/verification.md)을 참고하세요. 모든 검사를 최신 변경 후 한 번에 통과했다고 주장하지 않습니다.

Three.js 0.187.0과 MediaPipe Tasks Vision 1.2.2를 저장소에 고정합니다. 모델은 Google Face Landmarker float16 버전 1입니다. 출처는 [정적 자산 안내](assets/NOTICE.md), [기차 재질 안내](assets/train/NOTICE.md)를 참고하세요.

`resonance.mp4`, `afterimage.mp4`, `ready.mp4`는 이전 영상 관람 시제품의 자료이며 현재 관객 흐름에서 재생하지 않습니다. `npm run media`는 이 과거 합성 영상을 재생성하는 명령으로, 현재 도입·환경음을 만드는 명령이 아닙니다. `line.glb`도 보존 자료이며 전시에 삽입하지 않았습니다.
