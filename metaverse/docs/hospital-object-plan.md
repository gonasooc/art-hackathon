# 오브젝트 응시·깜빡임과 병원칸

최신 기획은 영상 관람을 대체한다. 00은 자궁의 추상적인 ‘빛의 씨앗’, 다음 01은 병원이다. 병원의 메인 오브젝트는 검은 표범과 금속 프레임 의자이며 사람은 배치하지 않는다.

## 흐름

기차 탑승 → 00칸에서 오브젝트에 시선 머무르기 → 짧게 눈 감았다 뜨기 → 오브젝트가 입자·연기 형태로 사라짐 → 전진하여 01 병원 → 표범과 의자를 각각 응시하고 깜빡임 → 둘 다 소멸한 뒤 출구까지 전진 → 종료.

오브젝트는 칸 내부에 배치하고, 접근 중에도 상호작용할 수 있다. 가까운 관찰 구간에서는 보행을 멈춰 오브젝트를 바라볼 시간을 준다. 모든 메인 오브젝트의 소멸이 끝나야 출구로 이어지는 이동이 열린다. 영상이나 영상 재생 버튼은 사용하지 않는다. 02–11은 아직 활성화하지 않는다.

## 깜빡임 판정

- 최신 유효 시선으로 3D 오브젝트를 raycast한다. 6m 이내의 실제 메시를 응시 대상으로 삼는다.
- 같은 대상에 약 180ms 시선을 두고, 마지막 유효 시선 이후 180ms 안에 눈 감음을 감지해야 한다.
- 양쪽 눈 감음을 확인하고 45–600ms 안에 다시 뜨면 한 번만 실행한다. 좌우 눈꺼풀이 조금 다른 프레임에 닫힐 수 있다.
- 윙크, 오래 눈 감음, 얼굴 이탈, 다른 오브젝트로 변경된 시선은 활성화하지 않는다. 눈을 뜬 직후 잠깐 대상이 잡히지 않으면 직전 응시 대상을 유지한다.
- 소멸 중이거나 이미 사라진 오브젝트는 다시 활성화하지 않는다. 탭 숨김, 재보정, 취소, 재시작에는 깜빡임 상태를 초기화한다.
- 소멸은 표면의 노이즈 기반 해체와 위로 퍼지는 부드러운 입자로 표현한다. 동작 줄이기에서는 상승·흩날림을 없애고 짧게 소멸시킨다.

레퍼런스에 보이는 사람은 포함하지 않는다. 표범과 의자는 이 프로젝트의 경량 3D 지오메트리로 구성한 스타일화 모델이며 원본의 실사 모델을 추출한 것이 아니다. 빈 병상·의료 모니터가 있는 관찰 공간을 더한다.

## 검증

깜빡임 상태 기계의 단위 검사와 실제 브라우저의 00 소멸 → 병원 이동 → 의자·표범 소멸 → 출구·종료 검사를 구분한다. 브라우저 검사는 합성 눈 특징과 시간 제어된 테스트 깜빡임을 추적기 경계에서 공급하며, 제품에는 입력 주입·우회 진입 API가 없다. 실제 사람의 깜빡임 성공률은 별도 확인이 필요하다.
