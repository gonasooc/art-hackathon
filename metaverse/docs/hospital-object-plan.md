# 오브젝트 응시·깜빡임과 병원칸

최신 기획은 영상 관람을 대체한다. 00은 오브젝트 없이 통과하는 자궁 공간, 다음 01은 병원이다. 병원의 메인 오브젝트는 검은 표범과 금속 프레임 의자이며 사람은 배치하지 않는다.

## 흐름

기차 탑승 → 오브젝트 없는 00칸 통과 → 01 병원 → 표범과 의자를 각각 응시하고 깜빡임 → 둘 다 소멸한 뒤 출구까지 전진 → 02 유년의 집(벽화·천장등·선반) → 03 놀이터(미끄럼틀·그네) → 04 카페(찻잔·의자·테이블) → 05 숲(이끼·잔설·나무) → 06 병원·임종(표범·수의로 덮인 몸·앤젤링) → 07 향이 놓인 자리(향) → 향 소멸 뒤 “No click, / one blink.” 연기 글씨 → 마지막 장면 유지.

오브젝트는 칸 내부에 배치하고, 접근 중에도 상호작용할 수 있다. 가까운 관찰 구간에서는 보행을 멈춰 오브젝트를 바라볼 시간을 준다. 모든 메인 오브젝트의 소멸이 끝나야 출구로 이어지는 이동이 열린다. 각 칸에서 작품 영상이나 영상 재생 버튼은 사용하지 않는다. 여정 전 별도의 [행성 도입 영상](planet-prologue.md)은 재생한다. 이번 MVP의 활성 순서는 00–07이며 08–14는 아직 활성화하지 않는다. 01–06은 모든 메인 오브젝트가 사라진 뒤 출구로 이어지고, 07은 마지막 연기 글씨로 이어진다.

## 깜빡임 판정

- 최신 유효 시선으로 3D 오브젝트를 raycast한다. 6m 이내의 실제 메시를 응시 대상으로 삼는다.
- 같은 대상에 약 180ms 시선을 두고, 마지막 유효 시선 이후 180ms 안에 눈 감음을 감지해야 한다.
- 양쪽 눈 감음을 확인하고 45–600ms 안에 다시 뜨면 한 번만 실행한다. 좌우 눈꺼풀이 조금 다른 프레임에 닫힐 수 있다.
- 윙크, 오래 눈 감음, 얼굴 이탈, 다른 오브젝트로 변경된 시선은 활성화하지 않는다. 눈을 뜬 직후 잠깐 대상이 잡히지 않으면 직전 응시 대상을 유지한다.
- 소멸 중이거나 이미 사라진 오브젝트는 다시 활성화하지 않는다. 탭 숨김, 재보정, 취소, 재시작에는 깜빡임 상태를 초기화한다.
- 소멸은 표면의 노이즈 기반 해체와 위로 퍼지는 부드러운 입자로 표현한다. 동작 줄이기에서는 상승·흩날림을 없애고 짧게 소멸시킨다.

## 검증

깜빡임 상태 기계의 단위 검사와 실제 브라우저의 00 무정지 통과 → 01–07 순서대로 이동 → 각 칸의 모든 오브젝트 소멸 → 마지막 연기 글씨 검사를 구분한다. 브라우저 검사는 합성 눈 특징과 시간 제어된 테스트 깜빡임을 추적기 경계에서 공급하며, 제품에는 입력 주입·우회 진입 API가 없다. 실제 사람의 깜빡임 성공률은 별도 확인이 필요하다.


## 2026-11-07 후속 변경

- 응시·깜빡임·소멸을 설명하는 화면 문구와 안내창을 제거했다.
- 병원의 메인 오브젝트에는 낮은 밝기의 윤곽빛이 천천히 변하고, 실제 응시가 잡히면 조금 선명해지는 시각적 신호만 둔다. 동작 줄이기에서는 신호의 주기적 변화를 끈다.
- 자궁칸의 씨앗을 제거하고, 상호작용을 요구하는 정지 없이 병원으로 이어지도록 했다.
- 응시 난이도 개선은 사용자가 의견을 요청한 단계다. 당시 제안에 따른 응시 영역 확대·감속은 구현하지 않았다. 현행 메시 기반 판정은 유지하고 보행 속도는 별도 요청으로 2.7m/s다. 추천은 오브젝트 전체 영역과 약 20%의 여유를 담은 아우라, 약 0.2초의 선택 유지이며, 접근 중 감속은 보조로 검토한다. 실제 구현 시 영역 중첩·추적 손실·오브젝트 전환을 따로 처리해야 한다.

## 소멸 속도 조정 · 2026-11-07

사용자 요청으로 모든 방의 공통 소멸 연출을 2.6초에서 1.3초로 단축했다. 동작 줄이기는 0.7초에서 0.35초로 단축했다. 응시·깜빡임 판정 조건과 소멸 이후 다음 방·피날레 진행 조건은 유지한다. 같은 소멸 함수를 쓰는 자동 시연과 수동 점검에도 적용된다.
