# 01·06 검은 표범 형상 보완

2026-11-07. 사용자 제공 `표범01.png`(정면·후면·측면)와 `표범02.png`(고개를 든 자세)를 기준으로 두 칸의 표범을 공통 `src/carriages/black-leopard.js`로 교체했다.

## 변경

- 길게 이어지는 몸통, 어깨와 엉덩이, 목을 가변 반지름 곡면으로 구성했다.
- 앞다리는 발목으로 좁아지고, 뒷다리는 허벅지·발목의 굽힘을 구분한다. 발과 발가락을 추가했다.
- 둥근 귀, 짧은 주둥이, 코, 황금색 눈·동공·눈썹, 얇은 수염을 구성했다.
- 긴 꼬리를 아래로 내려 끝을 위로 말고, 검은 털에 낮은 대비의 로제트와 미세한 결을 넣었다.
- 01은 기본 자세, 06은 고개를 약 13° 든 자세다. 기존 배치·크기 배율·대상 ID·응시점을 유지한다.
- 소멸 셰이더와 호환되는 MeshStandardMaterial만 사용한다. 사진을 평면 오브젝트로 붙이거나 외부 모델을 내려받지 않는다.

## 비교와 한계

`look-compare`의 inspection 프리셋으로 01·06을 렌더링하고 제공 이미지와 나란히 직접 확인했다. 위치 `[-5.45,2.67,-7.9]`, pitch -0.1865, yaw π/2, FOV 48°, ACES·노출 1.1이다. 비교 결과는 `.cache/leopard-review/01-final-vs-ref.png`, `06-final-vs-ref.png`에 있다. 06 비교는 마지막 곡면 보간·무늬 대비 조정 전이며 같은 공통 모델 변경이 두 칸에 적용된다.

판정은 **부분 반영**이다. 흰 배경의 세 방향 원본과 병원 조명 아래의 단일 장면이므로 전체 이미지의 명암·색 차이 수치는 동일 구도 재현 점수로 해석하지 않는다. 레퍼런스의 실사 털, 연속된 근육 표면과 얼굴 해부학적 디테일은 여전히 차이가 크다. 현재 결과는 실시간 절차형 모델이며 사진과 같은 재현이라고 주장하지 않는다.

두 칸 모두 실제 메시 raycast 첫 충돌, 1.3초 소멸·복원, 브라우저 오류 여부를 전용 `tests/browser/leopard.spec.mjs`로 검사한다. 실제 카메라 눈 추적과 전체 여정 회귀는 별도 범위다.
