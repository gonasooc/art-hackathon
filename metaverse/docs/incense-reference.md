# 07 향 — 영상 기준 공간과 피날레

2026-11-07 최신 기준은 사용자가 제공한 `~/Desktop/예술해커톤_영상/향.mp4`다. 이번 요청은 기존 향 공간의 구도·방향·색·비례·재질·조명을 영상에 맞추고, 마지막 장면을 영상으로 이어 붙이는 것이다. 이전 Figma 기반 절차형 글씨는 영상 재생 실패 시 복구용으로 남긴다.

## 현재 공간

- 검은 배경, 낮은 사각 석재 받침, 작은 밝은 도자기 향로와 가는 향·연기만 배치한다.
- 받침은 폭·깊이 0.85m, 높이 0.54m이며 Y축 약 -35.75°로 회전한다. 영상처럼 두 면과 윗면이 보인다. 상판도 같은 방향이며 향로를 받침 중심에 둔다.
- 영상의 모서리 좌표를 기준으로 관찰·전환 카메라를 `[-6.08, 2.19, -7.9]`, pitch 약 -0.027rad, yaw π/2로 맞췄다. 실제 이동 좌표는 변경하지 않고 관찰 시점만 정렬한다.
- 향로의 반지름은 이전 모델의 52%, 높이는 70%로 조정했다. 향은 0.6m 길이로 줄이고 받침 높이에 맞춰 함께 내렸다.
- 석재는 중성 회갈색 바탕과 가는 불규칙 맥, 바닥은 낮은 대비의 질감으로 구성한다. 좌측 위의 따뜻한 중성 스포트라이트, 낮은 보조광, 부드러운 접촉 그림자를 사용한다. 07 배경은 순수 검정이며 다른 칸의 렌더러·노출 설정은 유지한다.
- `07-incense`는 향로·재·향·불씨를 한 소멸 대상으로 묶으며 받침은 환경으로 남는다. 위치는 `[-9, TRAIN.floorY - .1, TRAIN.centerZ + .03245]`, 응시점은 `[-8.85, TRAIN.floorY + .65, TRAIN.centerZ + .03245]`다. 작아진 향로도 실제 메시 raycast로 확인했다.

## 영상 전환

`incense-finale.js`의 `IncenseFinale`가 영상과 정지 프레임·복구 장면을 관리한다.

1. 마지막 향에 유효한 깜빡임이 인식되어 소멸이 시작되면 영상 전환도 시작한다. 07 입장 때 영상 첫 프레임을 미리 준비하고, 카메라와 영상 투명도에 동일한 5차 곡선을 적용해 2.2초 동안 겹친다. 두 장면이 겹치는 동안 영상 첫 프레임을 고정하고 전환 완료 후 재생해 영상 속 카메라 이동과 3D 이동이 엇갈리지 않게 한다. 오브젝트 자체의 소멸 시간은 기존 1.3초를 유지한다.
2. `assets/films/incense-ending.mp4` 원본을 1회 재생한다. 1280×720, 24fps, 약 5.06초이며 오디오 트랙을 포함한다.
3. 화면은 영상 비율을 유지해 표시한다. 재생이 끝나면 마지막 디코딩 프레임을 유지하고 재시작·처음으로 조작이 열린다.
4. 영상은 항상 음소거한다. 사용자가 지정한 `SFX30_B_향.wav`와 동일한 `assets/audio/incense.wav`를 07부터 영상 전환·마지막 프레임까지 끊거나 처음으로 되돌리지 않고 반복한다. `ash.wav`로 바꾸지 않는다.
5. 동작 줄이기에서는 MP4를 요청하지 않고 4.8초에서 추출한 최종 정지 프레임을 0.6초 페이드한다. 이 경우에도 기존 향 음원을 이어간다.
6. 시연 일시정지·탭 숨김·수동 점검 일시정지에서 영상도 멈춘다. 복원·칸 변경·홈·재시작에서는 재생·전환 상태를 초기화한다.
7. 영상 로드 실패·재생 불가 또는 10초 이상 진행 정체 시 기존 절차형 3D 연기 글씨로 복구한다. 복구 시에도 향 음원을 유지한다.

영상의 향로·받침과 카메라 연출은 원본 그대로다. 전환 후까지 3D 객체의 소멸 상태와 영상 내부 사물을 동일한 것으로 취급하지 않는다.

## 비교와 한계

`look-compare`로 영상 첫 프레임과 실제 3D 렌더를 1280×720, FOV 48°, ACES·노출 1.1에서 나란히 확인했다. 비교 포즈는 `[-6.08, 2.19, -7.9, -.027, 1.5708]`이며 `poses.json`의 `07-film-opening`으로 재현할 수 있다.

- 비교 이미지: `.cache/incense-ending/final-match-vs-ref.png`.
- 평균 밝기는 원본 약 10 / 렌더 약 8, 채도는 0.17 / 0.15, 따뜻함(R−B)은 약 4 / 3이다. 어두운 영역 비중과 바닥 밝기 분포도 비교했다.
- 받침 방향·향로 비례·검은 배경·조명색을 보정했지만, 절차형 돌의 맥과 바닥 결·연기의 미세한 형태까지 픽셀 단위로 같지는 않다. 전환 후 장면은 원본 영상이다.
- 비교 렌더는 SwiftShader다. 실제 GPU·디스플레이의 최종 색과 실제 청취는 별도 확인 범위다.
