# 07 향

Figma 보드의 아래 다섯 노드를 직접 확인했다. 중앙 사진의 향을 중심으로 만들며, 별도의 가구나 장식은 추가하지 않는다.

- [중앙 향 사진 · 85:627](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=85-627): 검은 공간에 낮은 짙은 석재 받침, 옅은 도자기 향로, 향 한 개, 가늘게 올라오는 연기. 바닥에는 작은 따뜻한 빛의 영역이 있다.
- [위 · 66:73](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=66-73): 거의 완전히 검은 상부.
- [왼쪽 · 66:65](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=66-65): 어둠 속에 희미하게 드러나는 거친 바닥.
- [오른쪽 · 66:69](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=66-69): 반대 방향의 비어 있는 검은 공간과 바닥.
- [아래 · 66:80](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=66-80): 짙은 회갈색 바닥 질감.

`buildIncenseCarriage()`는 수동 환경 `group`, 별도로 부착하는 `targets`, `update(dt, reducedMotion)`과 마지막 장면을 담당하는 `finale`를 반환한다. `07-incense`는 향로·재·향·불씨를 하나의 소멸 대상으로 묶는다. 석재 받침은 환경으로 남는다. 시선 판정은 얇은 향만이 아니라 넓은 도자기 옆면에도 가능하다. 타깃 위치는 `[-9, TRAIN.floorY, TRAIN.centerZ]`, 응시점은 `[-8.704, TRAIN.floorY + .86, TRAIN.centerZ]`다.

검은 외피와 독립된 바닥을 제공하므로 기존 기차 외벽을 숨겨도 공간이 유지된다. 조명은 따뜻한 국소광이며, 세계 배경은 `0x030303`과 낮은 중성 환경광이 어울린다. 연기는 두 개의 부드러운 리본으로 천천히 올라간다. 타깃의 현재 투명도와 가시성을 따라 함께 사라지고, 동작 줄이기에서는 형태를 정지한다. 절차적 소형 텍스처를 사용하여 외부 이미지 다운로드 없이 실행된다.

## 향 소멸 뒤 마지막 장면

추가 [91:746](https://www.figma.com/board/FszUcDRVifUMnx9x15K1Z6/AKL-Team-1?node-id=91-746)을 Figma MCP로 확인했다. 검은 공간과 따뜻한 바닥 빛 위로 연기가 `No click,` / `one blink.` 두 줄을 이루는 구성이다. 사용자는 향이 사라진 **이후** 글씨가 피어나기를 요청했다.

`incense-finale.js`는 손글씨의 단일 획을 따르는 부드러운 입자와 연결된 반투명 연기 띠로 문구를 만든다. 화면에 붙은 자막이나 사진 배경이 아니라 같은 3D 공간 안의 요소다. 기존 향·향로 소멸이 완전히 끝나면 남아 있는 석재 받침 위에서 시작한다. 레퍼런스에 있는 향로를 다시 나타나게 하지는 않는다. 외부 폰트·이미지·영상·추론 의존성은 추가하지 않았다.

- 소멸 완료 전에는 글씨를 표시하지 않는다. 완료 후 약 6.5초에 걸쳐 형성하고 계속 남긴다.
- 마지막 구도를 담도록 4.5초 동안 카메라가 천천히 뒤로 이동한다. 롤·흔들림을 추가하지 않는다. 동작 줄이기에서는 최종 위치로 바로 전환하고 1초의 짧은 글씨 페이드만 사용한다.
- 일반 체험은 마지막 소멸 뒤 보행·눈 추적을 종료하고 `finale` 상태에 머문다. 기존 종료 패널이 화면을 가리지 않으며 문구 완성 후 하단의 재시작·처음으로 버튼만 표시한다.
- 자동 시연에서도 같은 소멸→글씨 장면으로 이어지며 일시정지·다시 시연을 지원한다. 별도 개발용 수동 점검 모드(`mode=inspect`)에서는 오브젝트 복원으로 글씨와 카메라를 초기화하고, 마우스·키보드 조작으로 자동 구도를 중단할 수 있다.
- `TrainWorld.resetFinale()`는 복원·칸 변경·홈·재시작 시 최종 장면 상태를 초기화한다.
