## 구현

`src/carriages/forest.js`의 `buildForestCarriage()`가 수동 배경 `group`, 별도로 등록할 `targets`, `lighting`, `update(dt, reducedMotion)`를 반환한다. 새 외부 의존성과 다운로드 에셋은 없다. 광물 표면은 작은 결정성 노이즈 텍스처를 코드로 만들고, 바위·고사리·황동 창틀·개방 천창·물길은 실제 입체로 구성한다.

| ID | 배치 | 검증용 응시점 |
| --- | --- | --- |
| `05-moss` | `[-8.08, 1.05, -6.54]` | `[-8.08, 1.77, -6.54]` |
| `05-snow` | `[-8.7, 1.05, -9.26]` | `[-8.7, 1.62, -9.26]` |
| `05-tree` | `[-10.5, 1.05, -6.5]` | `[-10.6, 2.47, -6.5]` |

이끼와 눈을 지우면 아래의 바위가 남는다. 나무는 뿌리·줄기·가지·잎이 함께 지워진다. 각 타깃은 로컬 원점에 만들어져 있으며 반환된 환경 그룹에 들어 있지 않다. 모두 기존 소멸 셰이더와 호환되는 `MeshStandardMaterial`을 쓴다. 배경 석판은 인스턴싱하고 나무의 가지는 병합해 드로우 콜을 줄였다.

중앙 보행 구간의 폭 `z = centerZ ± .78`을 비워 두며, 오브젝트는 그 양옆에 둔다. 행동 안내 문장이나 별도 응시 판정 확대·감속 기능은 없다. 기존 오브젝트 윤곽빛과 깜빡임 처리는 공통 시스템이 담당한다. 창밖 나무만 초당 .32m로 움직이며 객실·대상·카메라 위치에는 영향을 주지 않는다. 동작 줄이기를 사용하면 외부 움직임을 멈춘다.

조명 권장값은 반환 객체에 포함된다: 배경 `0x899a8c`, 안개 10–34m, 반구광 `0xe0e7d8`, 지면광 `0x566750`, 태양광 `0xf1e6ce`, 환경광 강도 .65. 이는 기존 분홍색 바깥 막과 기차 바디가 숨겨진 상태를 전제로 한다.

## 검증

- 독립 모듈 import 및 생성 확인.
- 헤드리스 Chromium에서 검사 카메라 `(-5.45, 2.67, -7.9)`, 목표 `(-9, 2, -7.9)`, FOV 48°로 렌더하고 화면 직접 확인. 브라우저 오류 0건.
- 이끼·잔설·소나무가 동시에 보이며 중앙 통로와 끝 문이 가려지지 않음을 확인.
- 외부 숲 움직임과 동작 줄이기 조건은 구조 검사로 검증. 공통 실제 눈 추적과 소멸 상태 전환은 통합 검증 대상.

재현용 이미지의 석재·황동·숲 관계를 저비용 절차적 지오메트리로 옮겼으므로, 원본의 실사급 반사·수면·식생 밀도까지 동일하게 재현한 것은 아니다.
