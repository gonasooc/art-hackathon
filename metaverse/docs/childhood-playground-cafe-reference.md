## 구현 범위

`src/carriages/childhood-home.js`, `playground.js`, `cafe.js`가 각 공간과 대상 메시를 반환한다. 목재·직물·흙·산수화·구름은 로컬 절차형 재질이며 별도 외부 네트워크나 이미지 생성 서비스가 필요 없다. 공통 창틀, 골조, 배경, 나뭇잎과 햇빛은 `memory-room-kit.js`에 둔다. 사진과 동일한 실사 렌더가 아닌 기존 객차와 같은 실시간 3D 해석이다.

나뭇잎은 인스턴싱한 양면 메시, 정적인 가지는 병합 메시로 그린다. 정적 그림자는 객차·오브젝트 상태가 바뀔 때만 갱신한다. 소프트웨어 WebGL에서는 렌더 해상도를 0.75배로 제한해 시선 입력을 처리할 시간을 확보하고, 일반 GPU에서는 기존 최대 1.5배 해상도를 유지한다. 기하와 필터링한 그림자는 양쪽에서 동일하다.

새 공간의 햇빛 그림자는 오브젝트 소멸 시 함께 끄고 복원 시 원래대로 되돌린다. 숲·임종·향의 기존 조명과 피날레는 유지한다. 집 창밖 담은 서서히 움직이며 동작 줄이기 설정에서는 멈춘다.

일반 시선 체험, 진행 중 자동 시연 전환, 수동 점검 모드 모두 같은 공간과 대상을 사용한다. 수동 점검 주소는 `?mode=inspect&car=02`, `car=03`, `car=04`다. 자동 시연은 별도 대상 선택 없이 기존 순서대로 응시·깜빡임을 수행한다.


카페의 최신 기준은 2026-11-07 제공된 로컬 영상과 01–07 이미지다. 문·가구·재질·풍경 수정과 비교 조건은 [카페 레퍼런스 검토](cafe-reference.md)를 따른다.
