# 행성에서 자궁 공간으로 이어지는 도입

사용자가 제공한 `예술해커톤_영상/행성-자궁.mp4`(1280×720, 24fps, 12.04초, 오디오 없음)를 확인했다. 사용자가 원본 영상 사용을 허용한 이번 요청에 한해 정적 자산 `assets/films/planet-womb.mp4`로 원본을 복사했다. `planet-womb.jpg`는 첫 프레임이다. 배포 매니페스트에 두 자산을 포함한다. 영상 트랙은 무음이지만 `JourneyAudio`가 별도 `assets/audio/prologue.mp3`를 영상 시간에 맞춰 재생한다. 동작 줄이기의 정지 프레임에는 이 영상 동기화 음원을 재생하지 않는다.

눈 보정·검증 뒤 영상을 자동 재생하고 10.4초부터 3.2초 동안 밝은 살구색의 마지막 풍경과 기존 3D 공간을 겹친다. 영상의 마지막 프레임을 유지하면서 소폭 확대·크로스페이드하고, 카메라만 기존 기차 앞 시점으로 이동한다. 내비게이션 거리·칸·오브젝트는 진행하지 않는다. 끝나면 기존 플랫폼 위치에서 눈 추적 이동을 재개한다. 동작 줄이기에서는 첫 정지 프레임 1.8초와 1.2초 페이드로 대체한다.

처음부터 시연·재시작은 도입부를 포함한다. 도입 중 자동 시연 전환은 현재 영상 시간을 보존하고, 체험이 시작된 뒤의 전환은 도입을 다시 재생하지 않는다. 일시정지·탭 숨김은 영상과 전환을 함께 멈춘다. 도입부는 건너뛰기 없이 재생한 뒤 기차 앞으로 이어진다. 로드 실패 시에는 기차 앞에서 계속하기를 제공한다.

원본 해당 시점과 브라우저 재생 화면을 나란히 비교했고, 전환 화면과 기존 플랫폼 도착 화면을 확인했다. 원본 영상의 실사 풍경을 전체 3D로 재현한 것은 아니며, 기존 공간과의 차이는 마지막 크로스페이드로 연결한다. 비교 스크립트의 PIL 의존성이 없어 추가 설치 없이 FFmpeg로 비교 이미지를 구성했다. `.cache/planet-reference/`의 화면은 배포하지 않는다.

사용자의 시간 제한에 따라 검증은 도입부 재생·전환·출발점 유지·중간 시연 전환·동작 줄이기·로드 실패 복구에 한정했다. 전체 객차 회귀 검사는 이번 변경에서 다시 실행하지 않았다.


현재 마우스 환경의 자동 시연 조작 영역은 평소 숨기고 주변 호버·키보드 포커스에서 표시한다. 터치에서는 항상 표시한다. 정상 도입 건너뛰기는 제거했으며 로드 실패 복구는 유지한다. 검증 결과는 [변경별 기록](verification.md)을 따른다.
