# 기차 탑승과 00칸 — 구현 기준

후속 [오브젝트·병원 기획](hospital-object-plan.md)이 영상 관람과 00칸만 구현한다는 범위를 대체한다. 현재는 00 자궁 → 01 병원 → 02 유년의 집 → 03 놀이터 → 04 카페 → 05 숲 → 06 병원·임종 → 07 향이 놓인 자리로 이어진다. 자궁은 오브젝트 없이 통과하고 이후 칸의 메인 오브젝트는 응시·깜빡임으로 소멸시킨다. 아래 표는 초기 00–11 기획 기록이다.

2026-11-06. 기존 아이트래킹 전시를 기차 여정으로 확장한다. 앞서 수정한 보정·독립 검증·부분 재확인, 시선 파티클, 낮은 진폭의 핸드헬드를 유지한다.

## 사용자 요청과 확정한 해석

1. 보정 후 진입하는 공간은 기차에 타기 전이다. 사용자의 앞에 기차와 열린 탑승문이 있다.
2. 유효한 시선으로 전진해 문을 통과하면 탑승한다. 클릭·키보드·타이머로 탑승하지 않는다.
3. 탑승 순간부터 기차가 움직이고 있다는 느낌을 준다. 창밖 풍경·선로·조명의 움직임으로 표현하고, 사용자 좌표를 기차 밖으로 운반하지 않는다.
4. 사용자는 기차 내부에서 기존 아이트래킹 방식으로 걷고 시야를 돌린다. 눈 감음·추적 실패에서는 사용자의 이동이 정지하며, 이미 출발한 기차의 배경 움직임은 계속될 수 있다.
5. 00–11의 칸은 각기 다른 기억이다. 이번 구현 대상은 00뿐이며 나머지는 흐름 정의만 둔다. 구현되지 않은 칸으로 이동하거나 그 안을 만든 것처럼 표시하지 않는다.
6. 흐름도에서 00은 ‘병원·탄생’이다. 사용자에게 확인한 결과 **이번 00칸 내부도 자궁을 추상적으로 표현**한다. 병실이나 실제 태아를 재현하지 않고, 반투명한 막·온기·부드러운 빛으로 탄생 전후의 감각을 만든다.
7. 기존의 ‘도착하면 영상 재생’은 00칸 안의 기억 지점에 연결한다. 관람 후 종료·재시작이 가능하다. 영상은 기존의 임시 추상 시청각 작품을 활용한다.

## 동작과 검증

- 탑승 전, 탑승 전환, 00칸 이동, 기억 관람, 종료를 구분한다.
- 기차 문과 계단으로 이어지는 제한된 접근 공간과 내부 통로에 충돌 경계를 둔다.
- 기차 주행감과 관객의 보행을 분리한다. 정지한 시선이나 끊긴 추적을 임의 전진으로 대체하지 않는다.
- 카메라의 큰 흔들림·롤 회전은 사용하지 않는다. 동작 줄이기에서는 장식적 주행 효과와 핸드헬드를 줄이거나 끈다.
- 칸 번호는 탑승해 00에 들어갈 때 실제 상태와 함께 갱신한다. 01–11은 활성화하지 않는다.
- 탑승 전후 스크린샷, 유효/무효 시선의 이동, 출발 시점, 내부 이동, 00 기억 지점, 종료·재시작, 기존 보정 재확인·시선 표시를 검증한다.

## 실제 확인과 보정 후속 작업

사용자는 로컬 기차 버전에서 ‘동작 잘 됨’이라고 확인했다. 동시에 세계관 진입 전 시선 검증 실패가 잦다고 보고했다. 제공한 진단은 GPU 경로, 방향 일치 4/6, 중앙 오차 약 0.241, 최대 오차 약 0.361, 흔들림 약 0.068이었다. 이는 초기화 로그 오류가 아니라 방향·위치 기준에서의 실패다.

허용 오차를 일괄 올리는 대신 다음을 보완했다.

- 첫 학습점 준비 시간을 1.8초, 이후 정착 시간을 0.9초로 둔다.
- 추론 결과 도착 시각이 아니라 프레임 촬영 시각이 정착 시간 이후인지 확인한다.
- 9개 학습점 내부의 leave-one-target-out 검사로 선형·2차 회귀 및 정규화 강도를 비교한다. 복잡한 모델의 이점이 작으면 선형을 선택한다.
- 보정·검증의 불투명 화면에서는 3D 재렌더링을 쉬어 추론에 GPU 시간을 확보한다.
- 독립 검증의 거리·방향·흔들림 기준과 최대 1회 부분 재확인은 유지한다.

훈련용 합성 데이터에서는 선형 관계에 선형 모델, 곡률이 있는 관계에 2차 모델이 선택되고 새로운 검증점도 통과하는 것을 확인했다. 이것만으로 실제 사용자의 실패율 개선을 주장하지 않는다.
