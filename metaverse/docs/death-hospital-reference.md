# 06 임종 병원 레퍼런스

## 확인한 자료

- Figma `AKL-Team-1`: `85:616`, `85:640`, `91:769`, `85:620`, `85:653`의 이미지를 MCP로 확인했다.
- 로컬 `임종병원.mp4`(8초)의 0.5초, 3초, 6초 프레임을 확인했다. 한글 파일명은 파일 시스템에서 NFD로 저장되어 있다.
- 프레임과 렌더 검증 이미지는 커밋 제외 경로 `.cache/death-references/`에 있다. 영상은 시각 참고로만 사용하며 웹페이지에서 재생하거나 배포하지 않는다.

## 반영한 공간과 오브젝트

짙은 적갈색 패널, 청록색 천장 형광등, 회색 바닥, 금속 프레임의 녹색 대기 의자, 관찰창과 블라인드, 뒤쪽 병원 양문을 구성했다. 관찰실과 대기의자에는 사람을 넣지 않았다. 레퍼런스 속 시신은 낮은 목재 단 위에 있으며, 구현에서도 침대 대신 낮은 목재 단을 사용한다.

세 개의 기억 오브젝트는 검은 표범, 천으로 완전히 덮인 몸, 상아색 천사 후광이다. 몸의 표면은 하나의 주름진 천으로 표현하며 얼굴·피부·상처는 노출하지 않는다. 후광은 날개가 아니라 두꺼운 빛나는 고리다. 앉은 눈높이에서 빈 중심이 보이도록 약 16도 기울였다.

영상, 행동 설명 문구, 응시 판정 확대, 이동 감속은 이 모듈에 포함하지 않는다. 응시 신호와 깜빡임 소멸은 공통 `MemoryObjects`가 처리한다.

## 통합 API

`buildDeathHospitalCarriage()`는 `{group, targets}`를 반환한다. `group`에는 공간과 조명만 들어 있으며, 각 target 그룹은 별도로 등록해야 한다. 모든 대상 메시 재질은 기존 소멸 셰이더와 호환되는 `MeshStandardMaterial`이다. 외부 이미지/모델 로딩 없이 기하와 작은 절차적 표범 텍스처를 생성한다.

| ID | 배치 좌표 | 시선 검증 좌표 |
| --- | --- | --- |
| `06-leopard` | `[-8.6, 1.05, -8.95]` | `[-8.6, 1.67, -8.95]` |
| `06-shroud` | `[-9.3, 1.23, -7.35]` | `[-9.27, 1.58, -7.35]` |
| `06-halo` | `[-9.25, 3.04, -7.25]` | `[-8.83675, 3.15883, -7.25]` |

후광의 aim은 빈 중심이 아닌 고리 표면을 가리킨다. 관찰 카메라 `[-5.45, 2.67, -7.9]`, lookAt `[-9, 2, -7.9]`, FOV 48°에서 세 aim이 모두 화면 안에 있으며 가장 먼저 각각 자기 오브젝트를 맞힌다. 거리도 각각 약 3.28m, 3.86m, 3.41m로 공통 6m 제한 이내다. 목표 전까지의 중앙 통로에는 가구를 두지 않았다.

공간 자체에 천장·벽·바닥이 있으므로 기존 기차 외장과 자궁 배경은 이 칸에서 숨긴다. 조명 권장 시작값은 배경 `0x101a18`, 반구 위 `0xc8e2d8`/아래 `0x232824`, 반구 강도 1.2, 주광 강도 0.65, 환경광 강도 0.18이다. 최종 밝기는 공통 렌더러의 환경맵과 함께 조정한다.

## 검증

- 모듈 구문 검사 및 Node에서 독립 생성 성공.
- Chromium 1440×900 실제 렌더 확인, 세 오브젝트 실루엣과 후광 구멍 확인.
- 각 aim에 대한 raycast가 자신의 오브젝트를 먼저 맞히는지 확인.
- 세 대상이 passive group에 포함되지 않는지, 대상 재질이 모두 표준 재질인지 확인.
- 실제 눈 추적·깜빡임 체감과 전체 칸 이동은 통합 검증 대상이다.
