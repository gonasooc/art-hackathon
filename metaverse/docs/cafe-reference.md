## 수정

- 커다란 아치형 끝벽을 낮은 목재 벽과 독립된 둥근 상단 문으로 교체했다. 문창은 막힌 반사판 대신 실제 개구부이며 작은 황동 손잡이를 둔다.
- 찻잔을 72% 크기의 흰 도자기로 바꾸고 금색 테두리를 제거했다. 잔 안 커피를 올리고 두 손잡이가 바깥을 향하도록 배치했다.
- 테이블은 가로로 긴 상판, 얇은 모서리, 중앙 기둥과 낮은 받침으로 조정했다.
- 안락의자는 분리된 타원체 대신 등과 양 팔걸이를 연결한 곡면, 둥근 쿠션과 짧은 목재 다리로 구성했다. 직물과 카펫의 요철을 낮추고 회색을 조정했다.
- 벽에 수직 패널과 낮은 걸레받이를 추가하고 책장 높이를 맞췄다. 천장 아치의 두께와 펜던트 개수를 줄였다.
- 측면에만 있던 산 배경을 객차 둘레로 이어지는 입체 지형으로 바꿨다. 거리별 색과 옅은 능선, 작은 수목, 절차형 구름 하늘을 사용한다. 다른 칸의 공통 배경과 렌더러 설정은 변경하지 않았다.

## 비교 조건과 판정

`look-compare/poses.json`에 `04-local-01`, `04-local-04`, `04-local-06` 비교 포즈를 등록했다. 원본 카메라 정보가 없어 **근사 구도**다. 전경과 근접 비교를 직접 확인했으며 우측 포즈는 후속 재현용으로 등록했다.

- 근접: `[-6.15, 2.67, -7.9, -0.20, 1.5708]`
- 전경: `[-2.3, 2.67, -7.9, 0.02, 1.5708]`
- 1600×1050, 세로 FOV 48°, ACES, 노출 1.1, SwiftShader.
- 비교 이미지: `.cache/cafe-review/final-wide-vs-ref.png`, `final-close-vs-ref.png`. 근접 이미지는 마지막 의자 하부·천장 조정 직전 상태다.

판정은 **부분 재현**이다. 목재 벽·독립문·회색 가구·작은 흰 찻잔으로 주요 형태를 수정했으나 사진 같은 직물, 미세한 구름, 계곡 안개와 숲 밀도는 남은 차이다. 기존 보행·출구 위치를 유지하여 후면 문까지 거리가 길며, 근접 화면에서 하늘이 차지하는 비율도 원본보다 크다. 이 구도 차이가 근접 화면의 밝기 통계에 크게 반영되므로 수치가 통과했다고 판단하지 않는다. 전경도 중간 높이의 밝기 분포 차이가 남는다. 실제 GPU의 최종 색·성능은 별도 확인이 필요하다.

## 동작 검증

카페의 세 대상 ID와 종류별 소멸은 유지한다. 잔 위치 변경에 맞춰 응시점을 `[-8.6, 2.15, -7.42]`로 이동하고 전체 여정 테스트의 좌표도 갱신했다. 전용 브라우저 검사는 실제 대상 메시의 raycast 첫 충돌, 6m 이내 판정, 소멸·복원을 확인한다. 제품 코드에 검사 전용 시선 주입 경로는 추가하지 않았다.
