## Design Context

### Users
예술 해커톤 발표자와 스크린을 함께 보는 관객. 관객 한 사람의 전송으로 작품이 시작되며, 실제 창작 기록과 샘플의 과정을 거쳐 다섯 결과물이 나온다. 사용자는 발표 시 화면이 작게 느껴지지 않기를 요청했다.

### Brand Personality
익숙함, 몰입, 절제. 평소 ChatGPT를 사용하는 기대에서 출발해 클릭 뒤의 인간의 시간으로 관객의 시선을 옮긴다. 화면 속 설명이나 제작용 표시는 몰입을 방해하므로 관객 화면에서 제외한다.

### Aesthetic Direction
사용자가 명시한 ChatGPT 화면의 어두운 UI를 유지한다. 기본 문구는 ‘딸깍으로 만들어줘’. 전송 후 잠시 ‘생각 중’을 보여준 다음, 같은 응답 영역이 화면 전체로 부드럽게 확장된다. 작품 재생 후에는 원래 대화의 위치로 돌아온다. 실제 브라우저의 전체 화면 API는 별도의 관람 설정이며 자동 전환에는 필요하지 않다.

플레이어 안은 재료와 수정의 흔적을 보여주는 전시처럼 구성한다. 종이색·먹색·산화철색·청회색을 사용하고, 가짜 붓·연필이나 인물 캐릭터는 쓰지 않는다. 공간 드로잉과 고친 문장, 겹친 회화, 재단선과 천의 접힘, 실제 소스의 타이핑, 음표의 시작·감쇠에 연결된 선의 장을 사용한다. 과정과 결과는 같은 형태를 공유하며 장면은 조용히 겹쳐 전환된다.

### Design Principles
1. 작품과 대화 화면의 위치 관계를 확장·복귀 동작으로 보여준다.
2. 인간의 행위가 읽히는 시간과 다섯 개별 결과의 순서를 보존한다.
3. 화면 확대는 transform과 opacity로 처리하고 매 프레임 레이아웃 계산을 피한다.
4. 정지·새 채팅·반복 재생·크기 변경에도 전환 상태가 남지 않게 한다.
5. 동작 줄이기를 설정한 환경에서는 확대 이동을 생략하고 같은 관람 순서를 유지한다.
